# TÉRMINOS DE USO - SISTEMA POS INTEGRADO

## 1. DESCRIPCIÓN DEL SERVICIO
- Software de punto de venta con integración a terminales existentes
- No procesamos pagos directamente
- Solo facilitamos comunicación entre su sistema y terminal

## 2. RESPONSABILIDADES
### Nuestra responsabilidad:
- Transmisión segura de datos de transacción
- Mantenimiento del software
- Soporte técnico básico

### Responsabilidad del cliente:
- Terminal POS y contratos bancarios
- Cumplimiento regulatorio de procesamiento
- Mantenimiento de certificaciones PCI DSS (si aplica)

## 3. LIMITACIÓN DE RESPONSABILIDAD
- No somos responsables de fallas en el terminal
- No garantizamos disponibilidad 24/7 del terminal
- Disputas de pago manejadas directamente con su banco

## 4. PROTECCIÓN DE DATOS
- No almacenamos datos de tarjetas de crédito
- Solo transmitimos montos e identificadores
- Comunicación cifrada SSL/TLS
